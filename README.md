# AI Face Detection System using Python and OpenCV

## 📌 Project Overview

This project is an AI-based Face Detection System developed using Python and OpenCV. It detects human faces in both images and real-time webcam videos using the Haar Cascade pre-trained model.

The system identifies the presence of faces, draws bounding boxes around detected faces, and displays the total number of faces detected in real time.

## 🚀 Features

* Face detection in images
* Real-time face detection using webcam
* Multiple face detection support
* Displays the number of detected faces
* Uses Haar Cascade pre-trained model

## 🛠️ Technologies Used

* Python
* OpenCV
* Haar Cascade Classifier
* Computer Vision

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <repository-link>
```

2. Install dependencies:

```bash
pip install opencv-python
```

3. Run image face detection:

```bash
python src/face_detection.py
```

4. Run real-time webcam face detection:

```bash
python src/webcam_face_detection.py
```
